Image Protection Architecture

1. Transparent Overlay Canvas Layer

Images are rendered directly onto standard HTML5 `` elements or beneath an absolute transparent overlay `

`. Standard user right-clicks or long-presses interact solely with the invisible top div.

2. Event & Shortcut Suppression

Global keyboard hooks block `Ctrl+S`, `Cmd+S`, `Ctrl+U`, `F12`, and `PrintScreen` commands. Context menus (`contextmenu`) and drag operations (`dragstart`) are disabled across all components.

3. Dynamic Canvas Watermarking

Watermark timestamps and owner signatures are rasterized into the canvas bitmap directly, ensuring any visual screen grabs retain copyright ownership markers.

Web Security Note: Client-side protection deters ~99% of general web users. True hardware screen-recording suppression requires specialized Digital Rights Management (DRM) or encrypted streaming (Widevine/FairPlay).
